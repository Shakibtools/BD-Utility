Simple Calculator সম্পর্কে

Simple Calculator বা সাধারণ ক্যালকুলেটর হলো একটি সহজ অনলাইন ক্যালকুলেটর যার মাধ্যমে দৈনন্দিন প্রয়োজনীয় যোগ, বিয়োগ, গুণ, ভাগ এবং percentage-এর হিসাব দ্রুত করা যায়। কোনো software বা app install করার প্রয়োজন নেই।

এই Calculator দিয়ে কী করা যায়?

  • যোগ / Addition
  • বিয়োগ / Subtraction
  • গুণ / Multiplication
  • ভাগ / Division
  • Percentage / শতকরা হিসাব
  • Decimal সংখ্যা দিয়ে হিসাব

Percentage হিসাব

Calculator-এর % button ব্যবহার করে percentage হিসাব করা যায়। যেমন 500 - 10% করলে ফলাফল হবে 450। একইভাবে 500 + 10% করলে 550 পাওয়া যাবে।

Keyboard দিয়েও ব্যবহার করুন

কম্পিউটারে keyboard ব্যবহার করেও calculator পরিচালনা করা যায়। Number, +, -, *, /, Enter, Backspace, Escape এবং % key ব্যবহার করা যাবে।
